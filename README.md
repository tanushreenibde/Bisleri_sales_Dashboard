Bisleri Water Sales Dashboard 📊

Project Overview

An interactive Microsoft Excel dashboard designed to analyze water bottle and jar sales over a five-year period.

Tools & Skills

- Microsoft Excel
- PivotTables and PivotCharts
- KPI reporting
- Data analysis and visualization
- Interactive slicers

Key Features

- Total Revenue
- Total Units Sold
- Total Orders
- Average Sales
- Year-wise Sales Analysis
- Monthly Sales Trends
- Product-wise Sales Analysis
- Product Category Sales Analysis
- Interactive filters for Year, City, and Salesperson

Dataset

The workbook contains synthetic sales data created for educational and portfolio purposes. It does not represent actual Bisleri company sales.
